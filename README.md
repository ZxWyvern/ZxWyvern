# ZxWyvern

**Game programmer · Gameplay systems · Narrative design**

I build games where the code, mechanics, and story support the same experience. My main work is in Unity and C#: gameplay systems, maintainable architecture, and the small details that make an interaction feel right. I also write stories and design game loops, especially for psychological horror and systems-driven games.

![Animated pixel-art night scene: a signal moves across a quiet landscape](assets/night-signal.gif)

## What I work on

- **Gameplay programming:** player interactions, AI behavior, state transitions, and game flow.
- **Engineering principles:** clear ownership, modular systems, decoupled dependencies, and code that a team can change without guessing what it will break.
- **Game design:** core loops, feedback, pacing, and turning a mechanic into a meaningful player decision.
- **Story writing:** character motivation, environmental storytelling, psychological tension, and narrative events that emerge through play.
- **AI-assisted development:** using AI for exploration, reviews, and workflow support while checking its output against the project and the actual code.

## Tools & practice

`C#` · `Unity` · `C++` · `SDL` · `Git` · `Linux` · `VContainer` · `Unity Input System` · `ScriptableObjects`

I prefer explicit interfaces, testable behavior, and a practical amount of abstraction. A good system should make the next change easier and keep the player's experience in focus.
